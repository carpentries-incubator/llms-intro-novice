# AI Carpentry: Exploring Large Language Models 
An introduction to Large Language Models as the central technology of LLM chatbots and coding assistants, for novice programmers working in research.
Part of AI Carpentry's [Learning Programming with GenAI](https://carpentries-incubator.github.io/ai-carpentry-user-workshop-novice/) workshop.

This lesson is in the early stages of development.
